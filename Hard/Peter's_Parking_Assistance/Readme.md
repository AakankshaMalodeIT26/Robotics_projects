Hardware Components : 

ULTRASONIC SENSOR

The Ultrasonic Sensor measures distance by using sound waves. The sensor consists of a transmitter and a receiver.
• The transmitter emits a sound wave and the receiver receives the waves reflected back from the target as an echo.
• The sensor measures the distance to the target by measuring the time taken between the transmission and reception.

BUZZER

The Buzzer is a audio signaling device that makes a buzzing sound.
The main working principle is based on the theory that, whenever an electric potential is applied across  a piezoelectric material, a pressure variation is generated. Thus creating an  audible sound wave.
